Personal rclone Google Drive Backup

This website describes a personal backup setup that uses rclone to transfer backup files from a privately managed server to the owner's Google Drive account.

The setup is used only by its owner for personal backup and recovery. It is not a public file-sharing service.

How it works

Rclone runs locally on the owner's server and communicates directly with Google Drive using Google's authentication and API services. Backup files are transferred to the owner's own Google Drive.
